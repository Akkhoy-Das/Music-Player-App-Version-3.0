# 🎵 MusicWave - Java Music Player

A simple desktop music player built with Java Swing. This application allows users to register, log in, manage their music library, create playlists, and play songs with an easy-to-use interface.

## ✨ Features

* User Registration & Login
* Add Songs to Library
* Play MP3 and Audio Files
* Create and Manage Playlists
* Favorite Songs System
* User-specific Music Library
* Volume Control
* Song Progress Bar
* Modern Java Swing Interface

## 🛠 Technologies Used

* Java
* Java Swing
* File Handling
* Object-Oriented Programming (OOP)
* JLayer Library (MP3 Support)

## 📂 Project Structure

```text
src/

├── Playlist.java
├── UserLibrary.java
├── UserManager.java
└── ...
```

## 🚀 How to Run

1. Download or clone the project.
2. Make sure Java JDK is installed.
3. Add the required `jlayer.jar` library.
4. Compile the source files.
5. Run `Main.java`.
